Kebijakan Privasi

Berlaku sejak 27 November 2026

Cuplik adalah aplikasi Windows untuk mengubah video panjang jadi klip pendek vertikal dengan AI, disediakan oleh PT Jipraks Digital Indonesia ("kami"). Halaman ini menjelaskan data apa yang dipakai Cuplik, dikirim ke mana, untuk apa, berapa lama disimpan, dan apa yang bisa kamu lakukan.

Ringkasnya

  • Kamu tidak perlu membuat akun, email, atau kata sandi untuk memakai Cuplik.
  • Proyek, video sumber, dan klip hasil render disimpan di komputermu.
  • Untuk mencari highlight, transkrip video dikirim ke layanan AI: AI bawaan kami atau layanan AI pilihanmu. Video dan suaranya tidak dikirim ke AI.
  • Klip hanya diunggah ke server kami kalau kamu menjadwalkan posting lewat Repliz.
  • Kami tidak menjual data kamu.

Data yang tersimpan di komputermu

Cuplik menyimpan data berikut di folder data aplikasi di komputermu (di Windows biasanya %APPDATA%\com.jipraks.ytshortclipper-v2):

  • Pengaturan: bahasa, pilihan AI, tampilan klip, waktu kamu menyetujui ketentuan ini, dan ID instalasi acak yang dibuat saat Cuplik pertama kali dijalankan.
  • Proyek: link dan judul video, transkrip, highlight, salinan video sumber beresolusi rendah, dan klip hasil render.
  • Logo yang kamu pasang untuk klip.
  • File cookies yang kamu impor supaya Cuplik bisa mengambil video. File ini berisi data login akun video kamu dan disimpan sebagai file biasa di folder data aplikasi.

Kunci akun AI bawaan, API key AI milikmu, serta access key dan secret key Repliz disimpan di Windows Credential Manager. Kalau penyimpanan itu gagal, kunci disimpan di file pengaturan di folder data aplikasi.

Data ini tidak kami terima, kecuali bagian yang disebut di bawah. Data terhapus kalau kamu menghapus proyek di aplikasi, menghapus folder data aplikasi, atau meng-uninstall Cuplik.

Data yang dikirim ke layanan AI

Untuk mencari highlight dan menulis judul, Cuplik mengirim teks berikut ke layanan AI:

  • Transkrip video beserta waktunya.
  • Judul video, nama channel, dan 500 karakter pertama deskripsi video.
  • Arahan atau prompt tambahan yang kamu tulis.
  • Untuk judul posting: judul klip, teks hook, dan konteksnya.

Video dan audio tidak pernah dikirim ke AI. Transkrip diambil dari subtitle video.

Kalau kamu memakai AI bawaan, teks ini dikirim ke server AI kami (ai-api.ytclip.org) yang meneruskannya ke penyedia model AI. Kami mencatat pemakaian per permintaan: model, jumlah token, biaya, waktu, dan pesan error jika ada.

Kalau kamu memakai API key sendiri, teks ini dan API key kamu dikirim langsung ke alamat layanan AI yang kamu pilih, misalnya OpenAI, Google Gemini, Groq, atau server lokal. Pemakaian data di sana diatur oleh kebijakan privasi layanan tersebut. Kalau kamu memilih preset YTClip AI (Web), permintaan dikirim ke server AI kami.

Akun AI bawaan dan saldo

Saat Cuplik dijalankan, aplikasi mendaftarkan akun anonim untuk perangkatmu ke server kami (api-v2.ytclip.org). Akun ini tidak memakai nama, email, atau nomor HP. Yang kami simpan:

  • ID akun, ID instalasi acak, platform (Windows), dan versi aplikasi.
  • Saldo, total top up, total pemakaian, dan tingkat member.
  • Riwayat top up: jumlah, biaya layanan, status, dan waktunya.
  • Catatan pemakaian AI seperti yang dijelaskan di atas.

Top up dibayar dengan QRIS lewat aplikasi bank atau e-wallet kamu. Pembayaran diproses oleh penyedia pembayaran kami. Kami tidak menerima nomor rekening, nomor kartu, atau PIN kamu.

Akun ini hanya bisa dipakai dengan kunci akun di komputermu. Kalau kunci itu hilang, kami tidak bisa memulihkan akun atau saldonya.

Posting lewat Repliz

Kalau kamu menjadwalkan posting dari Cuplik:

  • Klip yang dipilih diunggah ke penyimpanan cloud kami dengan nama file acak. File ini bisa dibuka oleh siapa pun yang punya tautannya, karena Repliz dan platform sosial perlu mengambilnya dari tautan itu.
  • Cuplik mengirim judul, deskripsi, tautan klip, akun tujuan, dan waktu posting ke Repliz memakai access key dan secret key Repliz milikmu.

Repliz dan platform sosial tujuan mengatur data posting sesuai kebijakan privasi mereka sendiri.

Mengambil video

Untuk mengambil informasi video, subtitle, pratinjau, dan potongan video, Cuplik menghubungi YouTube langsung dari komputermu, dengan file cookies kamu jika ada. Cuplik juga mengambil thumbnail dan info video dari YouTube, dan dapat mengunduh komponen pendukung dari GitHub dan model deteksi wajah dari Google Cloud Storage. Permintaan ini dikirim langsung dari komputermu ke layanan tersebut, bukan lewat server kami.

Statistik pemakaian

Setiap kali satu klip selesai dirender, Cuplik dapat mengirim satu catatan ke Google Analytics berisi ID instalasi acak, durasi klip, mode framing, versi aplikasi, dan waktu sesi. Isi video, judul, dan transkrip tidak dikirim. Google juga menerima alamat IP kamu saat catatan ini dikirim. Kami memakainya untuk tahu seberapa sering Cuplik dipakai.

Info aplikasi dan pembaruan

Saat dibuka, Cuplik mengambil info versi terbaru, pengumuman, dan isi menu Bantuan dari server kami. Permintaan ini tidak membawa data pribadi, tapi seperti semua koneksi internet, server menerima alamat IP kamu.

Untuk apa data dipakai

  • Menjalankan fitur Cuplik: mencari highlight, menulis judul, dan menjadwalkan posting.
  • Mengelola saldo AI, top up, dan pemakaian.
  • Mencegah penyalahgunaan, misalnya menonaktifkan akun yang dipakai untuk melanggar Syarat dan Ketentuan.
  • Memahami pemakaian aplikasi dan memperbaikinya.

Berbagi data

Kami tidak menjual data kamu. Kami hanya membagikan data kepada pihak yang dibutuhkan untuk menjalankan fitur di atas: penyedia model AI, penyedia pembayaran QRIS, penyedia penyimpanan cloud, Repliz saat kamu menjadwalkan posting, dan Google Analytics. Kami juga dapat membuka data jika diwajibkan oleh hukum yang berlaku di Indonesia.

Berapa lama data disimpan

  • Data di komputermu disimpan sampai kamu menghapusnya.
  • Akun AI bawaan, saldo, riwayat top up, dan catatan pemakaian disimpan selama akun ada, dan dapat disimpan lebih lama jika diwajibkan untuk keperluan pajak, akuntansi, atau hukum.
  • Klip yang diunggah untuk posting lewat Repliz tetap tersimpan di penyimpanan cloud kami sampai kamu meminta penghapusannya.

Hak kamu

Sesuai Undang-Undang Pelindungan Data Pribadi, kamu dapat meminta informasi tentang data kamu yang kami simpan, meminta salinannya, meminta perbaikan, atau meminta penghapusannya. Kirim permintaan ke help@jipraks.id dan sertakan ID akun dari halaman AI di Cuplik, supaya kami bisa menemukan datanya. Kalau akun AI bawaan dihapus, saldonya ikut hilang dan tidak bisa dikembalikan.

Keamanan

Koneksi Cuplik ke server kami memakai HTTPS, dan kunci akun serta API key disimpan di Windows Credential Manager. Tidak ada sistem yang aman sepenuhnya, jadi jaga komputermu dan jangan bagikan kunci akun, API key, atau file cookies kamu kepada orang lain.

Anak-anak

Cuplik tidak ditujukan untuk anak di bawah 13 tahun, dan kami tidak sengaja mengumpulkan data anak. Pengguna di bawah 18 tahun sebaiknya memakai Cuplik dan melakukan top up dengan izin orang tua atau wali.

Perubahan kebijakan

Kami dapat mengubah kebijakan ini, misalnya saat Cuplik mendapat fitur baru. Tanggal berlaku di atas akan diperbarui. Untuk perubahan penting, kami akan memberi tahu lewat aplikasi atau halaman ini.
